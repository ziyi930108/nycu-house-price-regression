# R85 前置誤差盤點與平方根面積方案審查

日期：2026-09-28。這是 CPU 保存向量的描述性分析，未新增模型、推論價格或提交檔。價格標籤只讀 canonical train；未讀 test 特徵或答案，未查外部成交價。

## 核驗方式

讀取既有 canonical 索引、三期 fit/query 索引及 v22、單價 base/reference/spatial、NN/log 保存預測。重新計算三期 v22 MAE 與原 R79 結果精確相同，並核對三分支逐筆中位數。共 39 個來源／程式 SHA，讀取前後一致；實測分析 4.96 秒，0 次訓練。

數值單位皆新臺幣元；偏差＝prediction−truth，正值代表高估。誤差占比＝群組總絕對誤差／全期總絕對誤差，不能與列數占比混用。真價分組只供事後診斷，不能用於 test 分流。

下一輪可預先固定、且不需要真價分流的假設：以 fit 端足量建案估計「建物型態／用途的時間斜率」，不足群維持原模型，並強收縮至全域斜率。需在擬合前固定分組、最小支持與收縮規則，重建各期 fit-only 狀態；不得依本次 query 最佳值挑群或比例。本輪不實作這項次要方向，避免與主候選混淆。

## 本輪固定主候選：平方根面積尺度

主執行緒已選定單一可驗證假設：保留日期權重及完整融合流程，只改單價 CatBoost 的目標表示與相應樣本權重。

~~~text
A = finite positive building_area, else positive parking_area, else 1
F = sqrt(A / 100)
target = (y_TWD / 1e6) / F
fit_weight = F * saved_date_weight
prediction_TWD = predicted_target * F * 1e6
~~~

既有單價形式是 F_old = A/100。以面積100／400／10000m²為例，舊恢復倍率為1／4／100，新倍率為1／2／10；這只是表示方式，不是直接壓低既有預測。新模型必須重新學習仍然隨面積增長的 target，不能把舊 unit 輸出直接乘新 F。

對任一列有精確代數關係：F*d*abs(y_million/F - z_hat) = d*abs(y_million - F*z_hat)。因此平方根表示搭配相同 F 的權重，仍對應日期加權的總價絕對誤差；它不是 log MAE，也不是改用未加權單價MAE。單調轉換只改了模型可表示的函數與最佳化幾何，尚未證明更有效。

本輪應保持 seed、樹數、深度、學習率、欄位、日期權重 bytes 不變；新單價 native 還原元後仍先 .75*new_native+.25*old_LGB，各自 reference/spatial，再與原 NN/log 逐筆 median。三期都執行，不因第一期結果提前挑版本；不改 v22 原始模型／提交。

### 明顯風險與必查反證

- CatBoost 的加權平均分母與正則化尺度會改變，不能把上式解釋成訓練器與舊模型完全相同或無額外最佳化影響。
- 平方根只減緩面積對還原倍率的增長，仍可外推，也可能低估大型完整交易；必須保留大面積、高價帶、車位與fallback群的退步。
- 有效面積 fallback=1 是數值約定，不能冒稱真實面積1m²。車位交易應單列監控。
- 廠辦的共同 reference/time 偏差仍存在，本輪表示改動不能宣稱已解決它。
- 一般100–200m²交易與新建案占主要誤差，不能僅展示某幾個億級案例；至少報告整體、既有重加權、新舊案、季度、城市、面積、型態與真價帶。
- 固定seed的GPU訓練並非位元決定性。既有2999樹對照不是同期重訓，改善不宜當純因果消融。
- 已反覆使用的三期 query 仍不是盲測。候選值凍結之後可另做合規時間切分穩定性檢查，不能用晚期模型回測更早query。
- 若要估計配對不確定性，使用建案及時間區塊而非只做逐列獨立重抽；區間亦不是Private勝率。

本次盤點沒有搜尋分群調價、Public比例、逐ID上限或query最佳常數；沒有產生候選價格。以上風險應與R85的實際訓練結果一起解讀，不能先宣布改善。
