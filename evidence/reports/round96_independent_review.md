## 方法與實作核對

- 三條原 v22 分支（NN、log、unit）的原生 base、時間趨勢與 fit 狀態保持。固定 `c_new=0.5*c`；`c>0` 列以 `P_new=B_future+0.5*(P-B_future)` 運算，`c=0` 列直接複製原 P。這是候選逐位定義，不聲稱與重新代入原 local-price 混合式逐位相同。原 local-price 有 `max(base,1)`，B_future 則沿原 raw base；原日期填補、366 日上限與正下限不另更改。
- 新 c 與新 P 確實傳入原 spatial；剩餘權重成 `(1-c_new)*alpha`，因此局部 reference 降低時空間修正份額可能增加。這是耦合機制測試，不能當成單獨 reference 的因果估計。
- 實核 549 個主鏈唯一檔案 SHA；另核 generic 的 80 個 source/input 雜湊項、決策的 9 個證據雜湊項，與既有保護檔案前後相等。計數範圍有重疊，不能相加當唯一檔案總數。
- 九分支保存 base/ref/spatial 與原控制逐位一致；新 P 公式、新 c、其餘 reference 診斷、spatial 不變欄位、effective weight 與保存 G/B_future 的計算全部核對。新 weight 未比原值減少。三期完整 median 與三支保存新 S 的中位數完全一致；所有五個舊控制完整 metrics 和 generic 完整 metrics 均對上原權威結果。
- 主流程保存向量及診斷完整重載、state/frame 前後不變檢查通過。本獨立審查再核保存向量算式；沒有重跑模型推論，也不把它稱為乾淨環境重新訓練。
