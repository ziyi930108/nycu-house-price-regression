# 回歸改良研究：2026-09-28

本輪完成四項固定假設、六次新CatBoost訓練、共十二組候選×年度評估。沒有找到足夠穩定、可替換使用者選定v22的新方法，因此保留全部模型與研究結果，不進全量訓練、不產生新的Kaggle CSV。Private仍未知。

## 做了哪些事，為什麼

1. **平方根面積尺度（R85）**：將總價除以sqrt(A/100)學習，權重同步改為sqrt(A/100)×既有日期權重，希望減緩面積帶來的外推倍率，仍對應日期加權總價絕對誤差。保留95欄及其他CatBoost參數，三期重新訓練。
2. **分組OOF價格先驗（R86）**：保留v22單價目標及權重，只加入一欄近期區域單價先驗，讓樹獲得平滑的地區價格尺度。訓練使用建案分組OOF，query只使用同窗fit狀態；三期重播來源驗證後重新訓練。NN歷史上已使用相關prior，不冒稱這是第一次使用。
3. **固定平均（R87）**：看過R85後，事前固定50/50平均R79與R85的原生總價，再與原LGB做75/25混合、重新套reference/spatial、與原NN/log取median。檢查兩種表示能否互補，沒有搜尋比例，不是平均最終CSV。
4. **無局部支持回退（R88）**：保留原v22，僅當reference沒有局部來源且spatial未套用時，各分支回到自己的未修正base。所有物件使用同一規則，檢驗共享時間趨勢在無局部支持時是否不適用。三支原始reference/spatial及diagnostics均先完整重播核對。

## 為什麼不換版本

- R85三期整體皆退步；但中間期原生單支改善約10萬元、部分中低價群改善。高價尾部及median選取抵銷收益，不能把單支的改善當成完整系統改善。
- R86最新期僅改善1,051元（約0.076%），另外兩期退步；最新期四個vs v22配對區間都跨零。5,000萬至1億價帶三期改善是有利反證，仍不足以覆蓋其他代價。
- R87兩期改善，最新期退步8,629元；vs v22十二個配對區間均跨零。最舊期收益主要來自171筆億元交易，最新期319筆億元交易又抵銷中低價收益，不能因「贏兩期」就採用。
- R88三期整體皆退步。沒有局部成交支持，不表示共享時間趨勢必然無效；這次固定撤銷政策不成立，也不代表所有分群趨勢方法都無用。

主對照仍為使用者選定的v22，次對照v24也保留。v24本來在三期整體MAE較低，但已回報Public較高；不能把v22描述成所有本機指標都最好。Public仍為1,998,568.5706元，沒有新增Kaggle分數。

## 防止洩漏與過擬合

原始課程價格為唯一標籤來源，沒有到內政部系統查答案。各年度fit/query索引、日期、地理、reference/spatial與舊控制完整向量均核對。R86先驗在fit端重播建案分組OOF；這不是時間OOF，每筆並不保證只看當日以前的fit成交。query標籤只用於評分與事後診斷。

所有候選先固定方法再計分，沒有依Public搜seed／比例或按test ID調價；R87、R88源於已看過的誤差結果，屬適應性研究。三個年度窗口已反覆使用，不是新盲測；建案與月份區塊bootstrap只描述這些窗口的配對不確定性，不能當Private勝率，也未校正選型偏差。固定seed的GPU訓練不保證位元決定性，v22原控制不是本輪同期重訓，微小差異不能作純因果結論。
