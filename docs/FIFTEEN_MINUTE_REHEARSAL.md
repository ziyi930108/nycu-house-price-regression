# 約15分鐘版的排練重點

先完整講一次第1至20頁，再依實際時間調整。主講規劃14:45是配速参考，尚未本人計時；問答與附錄不計主講。使用[現有排練頁](../teaching/v22_styles_20261001/fifteen_minute/deliverables/v22-15min-rehearsal.html)記錄時間與卡住位置，先下載到電腦再開啟。

## 第12頁：把估價起點說清楚

「這個神經網路先用參考單價乘上有效面積，得到總價起點，再學要乘多少倍率。」

這句可幫助理解原稿的「調高或調低多少」。實際上是乘倍率，不是加減固定金額。它描述其中一個神經網路的起點；第14頁則是三條分支各有初估後，再做成交參考與空間修正。

如果要確認自己懂了，可以試著回答：先驗神經網路的參考價，在組成三分支以前還是以後用？回答應是以前，之後這個網路的結果才與另一個網路平均、加入共同的LightGBM，形成其中一條分支。這是理解練習，不是額外必念段落。

程式對照：[先驗乘面積](../src/nn_prepare.py)、[網路倍率還原總價](../src/nn_predict.py)、[三分支配方](../src/predict_v22.py)。

## 第13頁：先講表格的三列

第一次介紹工具時，名稱與投影片對上即可。講到本頁，用手指或游標依次指出表格三列，說明「單價模型這一路」「兩個神經網路這一路」「總價與對數模型這一路」，再指出右欄是共同加入的同一個LightGBM。

每一路都是主要部分75%、共同模型25%。把1,000萬元和1,200萬元得到1,050萬元的例子講完，再說這還是修正前的初估。不要為趕時間把它縮成「六個模型直接平均」。第14頁三路分別完成修正，第15頁才取中位數。

第13頁稿子包含7次英文模型名稱，原50秒規劃可能偏緊。先自然講述並記錄，不必為貼合50秒加速念名稱。

## 估時還沒包括什麼

目前完整主講稿有4,051個純漢字，另有17次英文名稱或縮寫，包括全形MAE／OOF；数字多已寫成中文，沒有阿拉伯數字。另有兩個「〇」未納入原漢字計數規則。

若**假設**漢字每分鐘275字，每次英文名稱另需1–2秒，原14.73分鐘的文字估算會增加17–34秒，約為15.0–15.3分鐘。這只是在看估算對假設有多敏感，不是實際報告時間，也還沒包含切頁、指圖與停頓。不能用這個數字代替本人計時。

自然講完後，先看第12至15頁是否卡住，再看整段是否接近15分鐘。若偏長，優先減少重複念模型名稱與轉場；保留重要例子、Public／Private分工及方法限制。若少於12分鐘，檢查是否漏講理由或例子，不靠等待補時。未取得實際紀錄前，先保留目前已核准的講稿與三款簡報。
