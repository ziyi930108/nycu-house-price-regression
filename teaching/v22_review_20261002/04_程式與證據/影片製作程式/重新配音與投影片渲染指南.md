# 重新配音與投影片渲染

只要觀看或重組現有影片，請先用[影片README](README.md)。本目錄已附20張PNG、186段字幕時間與成品音軌；不需要為了重組而重新合成聲音。下面供確實要換旁白或改簡報時使用。

原影片是白底學術版第1–20頁，900秒、1080p、15fps。Windows本機Microsoft Hanhan Desktop合成旁白，Rate 2原音加停頓後，約1.052倍速度調整；不是使用者錄音或真人計時。原配音WAV、Windows聲音、FFmpeg及簡報runtime未附入repo。

## 要改投影片時

先看[審查版PPTX重建入口](../../../../docs/REVIEW_TEACHING_REBUILD.md)。該入口使用repo內的[前版三款PPTX](../../../v22_styles_20261001/fifteen_minute/README.md)、本版notes/narrative與明確提供的runtime，在新目錄產生最新三款和69張PNG。它只重建既定備忘稿，不是任意新文案生成器。

要改稿時另開新版本，同步narrative、notes計畫及配音輸入並重新核對來源，不移除雜湊或拒覆寫檢查。不要將原影片配音搭配已改意思的投影片卻聲稱一致。

## 要重新配音時

需要Windows PowerShell的System.Speech及可用的Microsoft Hanhan Desktop聲音。不同聲音或版本可能改變時長和發音。FFmpeg需要libx264、AAC、atempo與subtitles/libass，以及Microsoft JhengHei字型；程式不會自動安裝。請先切到本審查目錄根（有01至05子目錄的位置），下列輸出目錄必須不存在。

```powershell
$pack = (Get-Location).Path
$videoSource = Join-Path $pack '04_程式與證據/影片製作程式'
$job = Join-Path (Split-Path $pack -Parent) 'v22-new-voice'
if (Test-Path -LiteralPath $job) { throw '請使用尚不存在的新工作目錄。' }
$videoPython = Read-Host 'Python 3.10以上執行檔完整路徑'
$ffmpeg = Read-Host '具備libass的FFmpeg執行檔完整路徑'
$null = New-Item -ItemType Directory -Path $job
$audio = Join-Path $job 'audio_rate2'
$speech = Join-Path $videoSource 'speech_input.json'
powershell.exe -NoProfile -File (Join-Path $videoSource 'synthesize_segments.ps1') -InputJson $speech -OutputDirectory $audio -VoiceName 'Microsoft Hanhan Desktop' -Rate 2 -SampleRate 22050
if ($LASTEXITCODE -ne 0) { throw '語音合成失敗，請保留日誌。' }
```

若只換聲音、投影片內容完全相同，可沿用包內PNG。影片編譯器用連字號檔名，而保存素材用底線；先複製到新目錄，不修改原素材：

```powershell
$renders = Join-Path $job 'renders'
$null = New-Item -ItemType Directory -Path $renders
1..20 | ForEach-Object {
    $sourceName = 'slide_{0:D2}.png' -f $_
    $targetName = 'slide-{0:D2}.png' -f $_
    Copy-Item -LiteralPath (Join-Path $videoSource ('video_assets/' + $sourceName)) -Destination (Join-Path $renders $targetName)
}
& $videoPython -B -X utf8 (Join-Path $videoSource 'build_video.py') --audio-dir $audio --input-json $speech --renders $renders --ffmpeg $ffmpeg --output-dir (Join-Path $job 'video')
if ($LASTEXITCODE -ne 0) { throw '影片編譯失敗，請查看新輸出與failure.json。' }
```

若用了新渲染，將`$renders`指向其A款前20頁。第21–23頁附錄不入片。新的`main.mp4`、SRT/VTT、章節及receipt會寫入新video目錄；速度調整僅接受0.8–1.2倍，超出會停下，不刪尾句湊時間。更換語速請另開音訊目錄。

## 實測與限制

原影片曾完成本機配音和編碼；後續保存素材重組另實跑52.693秒，整檔MP4 SHA相同。上述repo版重新配音流程是依現有CLI整理的操作指南，本輪沒有重新生成186個WAV或從配音到影片整鏈重跑，也未驗證全新電腦安裝。字幕仍是句子邊界估計，未人工逐句聽音或逐字強制對齊。

`build_video_before_probe_fix.py`、`recover_video_receipt.py`保留原章節檢查誤判的歷史，不應串成新建流程。其他prepare/assemble/package等腳本也是原工作區紀錄；新環境使用上述明確參數入口。v22模型與提交価格保持。
