# 單頁補充講稿

這一頁用v25配方另外做一次診斷重跑，補上老師要求的訓練與驗證曲線。原v25的模型和提交價格都保持，這不是它當時每一輪的原始軌跡。橫軸是同一個神經網路從第一輪到第三十輪的學習過程，模型大小一直相同。縱軸是平均總價誤差，單位是萬元，越低越好。藍線用模型學過的交易計算，橘線用時間較晚、沒有參與這期訓練的交易計算。每一輪都關閉 dropout，兩條線也都不用日期權重，讓誤差的單位一致。第三十輪時，訓練誤差約71.50萬元，時間驗證約177.71萬元。驗證後段有波動，沒有持續上升的典型U形，因此不能只憑這張圖斷言沒有過擬合。這張圖只看先驗神經網路的一個原生分量，還沒有加入其他模型、成交參考或中位數。另外，兩組的先驗建立方式不同，因此不能只看線與線的距離，就直接判定過擬合。原本的設定已固定三十輪，沒有看這張圖再挑最好的一輪。
