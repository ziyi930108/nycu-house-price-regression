# 臺灣房價預測 v22 零基礎報告

2026-10-01｜課程專題正式說明與自學版本

本報告說明選定提交模型 v22 的完整流程、設計理由、實際成果與證據界線。

### 研究成果與閱讀方式

本專題要回答一個具體問題：只知道一筆交易的面積、地區、樓層、房屋型態與交易時間等資料，能否預測它的成交總價？我們以課程提供的已知交易學習規律，再對沒有價格標籤的 47,073 筆測試交易產生價格。選定提交檔名為 submission_v22_trial.csv，以下簡稱 v22。

v22 是回歸模型的組合：六個模型產生不同角度的估價，整理為三條分支，利用訓練資料中的可比成交與空間資訊修正，最後每筆取三個結果的中位數。單價 CatBoost 另採面積權重與 365 日半衰期的近期成交權重。

## 回歸與平均絕對誤差

### 從一張交易表理解模型

一列資料代表一筆交易。「特徵」是模型可看到的描述，例如建物面積、地區和樓層；「標籤」是已知的正確答案，本題為總價元。訓練時模型同時看到特徵和標籤，反覆調整內部參數，讓估價誤差變小。這就是監督式學習。

推論是使用已學好的規則，對新資料算出結果；這時不提供新資料的真實總價。模型輸出 1,020 萬元之類的連續數值，屬於回歸。若任務是判斷「高價或低價」等類別，才屬於分類。本題沒有把價格改成類別。

### 用兩筆假設交易手算 MAE

| 交易 | 實際總價 | 預測總價 | 絕對誤差 |
| --- | --- | --- | --- |
| A | 1,000 萬元 | 1,100 萬元 | 100 萬元 |
| B | 1,000 萬元 | 950 萬元 | 50 萬元 |

```text
A 的誤差 = |1,000 - 1,100| = 100 萬元
B 的誤差 = |1,000 - 950| = 50 萬元
MAE = (100 + 50) / 2 = 75 萬元
```

絕對值把高估與低估都轉成正的差距，因此兩者不會互相抵銷。將每筆的絕對差加總、除以筆數，就是平均絕對誤差 MAE。若以元輸入，結果也是元；越小越好。上表完全是假設教學數字，不是課程交易或模型實測結果。

### MAE 可以說什麼

Public MAE 約 199.86 萬元，表示公開評分的那些交易，平均絕對總價差約為 199.86 萬元。它不是「準確率 多少％」，也不表示每間房都只差 199.86 萬元。少量非常大的誤差也可能提高平均值，因此後面還會檢查高價群等子群。

訓練時的 loss 是模型用來調整參數的誤差函數。各模型可在單價或 log 尺度學習，但本專題的最終評估一律把輸出還原成新臺幣總價，再算 MAE，避免把不同單位的結果混在一起。

資料的名字不一定代表本專題實際用法。valid 雖然叫驗證集，這套流程的年度回測用的是 train 內的時間切分；valid 是最後訓練提交模型時才加入。sample 的價格是格式範例，不能當答案。

### 為何先清理再學習

train 混入 3 列英文表頭，先移除，再比對除編號以外的全部原始欄位，連同目標價格一起檢查完全重複。這樣可避免同一份交易紀錄被重複加重，而不會因不同交易恰好使用同一編號就誤刪。

```text
455,787 - 3 列表頭 = 455,784
455,784 - 529 列完全重複 = 455,255
455,255 + 11,994 列 valid = 467,249
467,249 - 28 列跨集完全重複 = 467,221
```

test 的 47,073 列全部保留，不去重、不刪掉難預測的案例。輸出必須依 sample 的編號順序，否則即使價格數值合理，也會配到錯誤房屋。

### 價格來源與可用資訊

標籤及價格參考都來自課程資料，沒有到內政部不動產成交案件實際資訊資料供應系統對 test 答案。另使用既有 OpenStreetMap／Geofabrik 的非價格道路快照作地理特徵，來源與檔案身分有保存，所以不能說模型只使用原始四份檔案。

Public 約占 test 的 30%，Private 為其餘約 70%。這是 Kaggle 對 test 的評分分割，與上表 valid 是不同件事。Private 真價不在本地資料中，不能把預測向量差或歷史回測誤稱為 Private 成績。

## 把交易描述變成模型可用特徵

原始表格常把數值、文字和日期混在一起。特徵處理的目的，是把同樣意思整理成一致表示，並保留缺失資訊，讓模型能比較交易。處理規則必須在訓練與推論時一致。

| 資料類型 | 實際處理或衍生 | 設計理由 |
| --- | --- | --- |
| 面積與組成 | 土地、建物、車位面積及比例；交易筆棟數 | 同樣總價可能包含不同規模或組成 |
| 樓層與格局 | 解析中文樓層、總樓層、房廳衛等 | 文字須轉成一致表示，才能比較位置與配置 |
| 時間 | 解析民國交易日期及異常旗標 | 讓模型辨識成交時點與市場差異 |
| 地區與地址 | 保留地區、道路、建案等類別 | 位置與同區交易可提供價格背景 |
| 道路地理 | 道路代表點、長度、範圍、網格與匹配狀態 | 補充粗略空間位置；不能當精確門牌座標 |

### 哪些欄位不給模型

編號只是資料識別碼，不當作估價依據；總價是要預測的標籤，不放進輸入。建築完成年月在這批資料中不可用，管理組織欄為常數，均排除。完整備註與解約情形不納入，只保留有限非價格備註旗標，降低價格文字或交易後資訊進入模型的風險。

缺值不等於零。數字文字需轉換，日期或樓層無法解析時保留適當缺失、異常旗標；類別缺值以 __MISSING__ 表示。模型可以利用「這欄沒有資料」的狀態，不必假裝知道真值。

### 欄數要說清楚

共同基礎有 87 欄。近期加權單價 CatBoost 再加入 8 欄道路地理特徵，合計 95 欄，其中 23 欄是類別。神經網路另有編碼，數值維度不同，不能說六個模型都吃相同的 95 欄。

各年度回測採對應年度道路快照；代表位置依道路而來，不是房屋的精準座標。地址不完整、道路匹配失敗或新建案仍會造成資訊不足。這些特徵是合理的資訊補充，本文沒有將每一欄的效果當成已做過單獨實驗的結論。

依據：S1、S4、S9。完整路徑見末頁。

## 用過去預測以後的時間回測

如果模型只是記住已看過的交易，訓練誤差可能很低，但面對新交易仍會失準。這稱為過擬合。要檢查模型能否推廣，必須用沒有參與該次學習的資料評估。

### 本專題的三個年度切分

| 評估期間  含起訖日 | 較早 fit 筆數 | query 筆數 |
| --- | --- | --- |
| 2021-08-11 至 2022-08-10 | 134,805 | 105,511 |
| 2022-08-11 至 2023-08-10 | 240,316 | 81,234 |
| 2023-08-11 至 2024-08-10 | 321,550 | 133,697 |

fit 是用來學習的資料；query 是這次要預測、事後才拿真價評分的資料。每個年度只用起點以前的 train 建立當期模型，評估接下來一年。這較接近「拿過去成交估計後來交易」的使用方式，也能觀察市場改變時的表現。

### 只分開表格還不夠

價格先驗、編碼器、可比成交參考與空間修正都可能記住訓練資訊，所以必須與模型一起依當期 fit 建立。不能先用全部年度算出一個區域均價，再回頭聲稱較早年份是沒看過答案的測試。也不能拿後期模型只換評分索引來回測。

資料洩漏是模型在學習或生成輸入時，意外用到評估時不應知道的答案或資訊。例如把 query 真價放進區域參考價格，即使沒有把「總價元」直接給主模型，也已經洩漏。

### 時間回測仍有界線

同一批三年度窗口已被多輪研究反覆使用，選型可能逐漸適應這些題目；它們不是全新盲測。分群分析和重抽樣區間能幫助發現不穩定，卻不會自動消除反覆挑選造成的偏差。

原 v22 各窗道路快照為 2021、2022、2023 年 1 月 1 日，均早於對應 8 月 11 日的切點；最終模型使用 2024 年 1 月 1 日快照。這支持快照日期的對應關係，但不把粗略道路定位當精確住宅位置。

依據：S1、S2、S5、S9。完整路徑見末頁。

## 六個回歸模型各自學什麼

### 樹模型與神經網路的直覺

回歸樹會依條件逐步分組，例如面積較大或較小、位於哪類地區，再對每個群體估價。梯度提升樹會接續加入多棵樹，逐步修正先前估計的誤差。CatBoost 與 LightGBM 都屬於這類模型，但建立與處理資料的方式不同。

表格神經網路把數值與類別的數字表示傳過多層可調整的運算，學習特徵之間的關係。類別 embedding 是由訓練學出的數字表示，不是把行政區名稱當成有大小順序的整數。

| 模型代號 | 學習表示 | 為何保留這個角度 |
| --- | --- | --- |
| C_unit | 近期加權單價 CatBoost | 先將總價按面積縮放，再還原總價 |
| L_unit | 單價 LightGBM | 提供另一種樹模型的估計 |
| C_raw | 直接總價 CatBoost | 直接學習原價格尺度 |
| C_log | log 總價 CatBoost | 壓縮價格尺度，形成不同誤差取捨 |
| N_area | 面積連結神經網路 | 由數值與類別表示學單價，再乘面積 |
| N_prior | 先驗倍率神經網路 | 從區域參考單價出發，學習調整倍率 |

### 為何不只留一個模型

房屋價格可能同時受規模、位置與市場時點影響。不同表示法和模型可能在不同交易上有不同偏差，因此組合它們是值得測試的假設。但模型種類多，不代表必然更準；如果錯在同一方向，組合仍會錯。

v22 不是直接把六個模型平均。先把每個輸出還原成總價元，再形成三條分支，最後取中位數。L_unit 被三條分支共用，不是三個額外模型。第 10 頁列出精確配方。

本次單價 CatBoost 的主要設定為 2,999 棵樹、深度 8、learning rate 0.065、seed 42、MAE 目標與 GPU 訓練。這些是保存配方，不是適用所有房價資料的最佳參數；不能用固定 seed 保證所有 GPU 重訓結果逐位相同。

## 單價表示與面積權重

### 先分開規模與價格水準

總價同時包含房屋規模和單位面積的價格水準。以單價表示學習，是希望模型比較相近的價格尺度，再利用已知面積還原總價。這是建模轉換，不是把評分改成單價 MAE。

有效面積 A 優先採正且有限的建物面積；不可用時改採正且有限的車位面積；都不可用則取 1。這是防止除以零或缺值的縮放規則，不能解釋成真實室內面積，更不是補猜房屋面積。

```text
學習目標 = 總價 y / (有效面積 A × 10,000)
輸出還原 = max(預測單價 × A × 10,000, 0)
樣本權重 = (A / 100) × 日期權重
```

目標的單位可讀作「每平方公尺的萬元」。假設一筆交易總價 1,000 萬元、有效面積 100 平方公尺，學習目標就是 10。若預測為 11，換回總價為 1,100 萬元，總價誤差為 100 萬元。

### 為何單價還要乘面積權重

同樣每平方公尺錯 1 萬元，50 平方公尺會錯 50 萬元，100 平方公尺會錯 100 萬元。若兩筆在單價誤差裡占相同比重，就沒有反映本題關心的總價差距。因此用面積 A/100 加權。

```text
(A / 100) × 日期權重 × |y / (A × 10,000) - 預測單價|
= 日期權重 × |y - 還原總價| / 1,000,000
```

上式在非負輸出裁切前成立。右邊是總價絕對誤差乘上日期權重，再除以固定常數。因此單價的表示法與總價誤差能相互對應；它不是百分比誤差，也沒有給每一間房相同的相對誤差成本。

### 這項設計的代價

較大面積交易的總價誤差可能很大，異常面積或高價物件也更難估。回退規則只保障數值可計算，不能保證資料正確。應以有標籤回測檢查高價群，而不能看到 test 預測很大就依未知真價逐筆改價。

## 近期權重與對數價格

### 為何讓近期成交比較有分量

市場可能隨時間改變。用很早的成交和最近成交同樣重視，不一定最適合預測後來交易，因此讓近期樣本在訓練誤差中占較高比重。這是假設近期市場更有參考性，不是保證舊資料無用；舊交易仍保留，只降低相對權重。

```text
原始日期權重 u = 2 ^ (-距 fit 最新有效日期的天數 / 365)
有效日期的最終權重 = u / 所有有效 fit 日期的 u 平均值
缺失或異常日期的權重 = 1
```

| 距基準日期 | 正規化前相對權重 | 白話意義 |
| --- | --- | --- |
| 0 天 | 1 | 相對基準 |
| 365 天 | 0.5 | 與新一年成交相比為一半 |
| 730 天 | 0.25 | 兩年每隔一年再減半 |

表中的 1、0.5、0.25 是正規化前的相對例子，最終權重還會除以有效 fit 權重平均值。兩筆相差 365 天的有效成交，比例仍為 1 比 2。單價 CatBoost 保存實作沿用已核對列序的保存 float32 日期權重，轉 float64 後乘上面積權重，沒有重新正規化。

日期加權的對照只改單價 CatBoost，其餘分支保持；原本的 log 模型與先驗 NN 也已有日期加權，不能把對照說成「完全沒用時間資訊」。歷史三期整體點估計改善，但部分高價群退步，中間年度的配對區間跨 0。

### 為何還保留 log 模型

log 可以把原本差距很大的價格縮到較接近的數值範圍。例如 100 萬與 1 億相差 100 倍，轉換後數值差會縮小，使模型以另一種尺度分配誤差重點。log 不是將高價改成低價，也不是刪掉高價資料。

```text
學習目標 z = log1p(y / 1,000,000)
輸出還原 = max(expm1(z) × 1,000,000, 0)
```

log1p 是 log(1+x)，expm1 是其反向轉換。這支模型在 log 空間使用近期加權 MAE，並不等於直接最小化元的 MAE。保留它是為了提供不同估計角度，最終仍還原成元，交由完整組合的總價 MAE 判斷效果。

## 神經網路與不偷看自己的價格先驗

### 兩個神經網路的任務

面積 NN 用交易特徵學單價，再乘有效面積還原總價。先驗 NN 則先取得區域的參考單價，再學習這筆交易應該比參考高或低多少倍。先驗不是 test 答案，只是由該次 fit 的價格建立的起始估計。

假設教學情境中，某區域參考單價是每平方公尺 10 萬元，倍率模型估計 1.1 倍，有效面積 100 平方公尺，還原總價便為 10 × 1.1 × 100 = 1,100 萬元。這組數字只用來說明倍率，不是模型真實輸出。

### 為何不能直接用自己的成交價作提示

若先驗包含這筆交易自己的價格，訓練時模型會得到一個過分接近答案的提示；到了沒有答案的 test，提示就沒那麼完美。為了降低這種差異，訓練先驗使用按建案分組的五折 OOF。

| 階段 | 實際做法 |
| --- | --- |
| 分成五折 | 同建案放在同一折，避免同建案成交分散到兩邊 |
| 製作訓練先驗 | 每一折只用另外四折的 fit 價格建立先驗，再提供給該折 |
| 製作 query 先驗 | 以這次全部 fit 建立保存先驗，套用到 query；不使用 query 真價 |

OOF 是 out-of-fold，意思是「由自己所在那一折之外的資料計算」。這裡五折是分組數，不是五個先驗欄。先驗提供每筆一個參考單價；兩個 NN 的整體數值輸入分別為 603 維與 144 維，另加類別 embedding。

### OOF 與時間切分解決不同問題

這是建案分組 OOF，不是時間 OOF。它避免本建案標籤直接進入自己的訓練先驗，但不能說每筆訓練先驗都只用其成交日以前的交易。年度 query 仍在外層時間切分之外，不參與當期先驗建立。

兩個 NN 共用 512、256、128 的隱藏層架構，訓練 30 個 epochs，使用 Dropout 0.1 等設定。Dropout 會在訓練暫時遮掉部分表示，降低只依賴少數連結的傾向；它只是控制過擬合的一種設計，不能取代外部評估或保證泛化。

## 成交參考與三條分支的中位數

先將六個模型的預測全部還原成總價元。下面的 C、L、N 代號對應第 6 頁的模型，B 代表還沒做成交參考修正的分支初估。

```text
B_unit = 0.75 × C_unit + 0.25 × L_unit
B_nn   = 0.75 × (0.5 × N_area + 0.5 × N_prior) + 0.25 × L_unit
B_log  = 0.75 × (0.5 × C_raw + 0.5 × C_log) + 0.25 × L_unit
```

### 每條分支先修正，再一起取中位數

第一步 R 用 fit 中同建案、地址、道路等可比交易，以及 fit 估計的時間趨勢修正初估。這如同估價時參考已知的相似成交，但來源是保存的訓練資料，不是上網查 test 真價。

第二步 S 在原參考支持較弱時，利用空間上附近其他建案補充，同時參考原初估與 R 的結果；支持不足時回退。它不是直接平均附近全部成交，也不是將 test 自己的真價填回模型。

```text
U = S(B_unit, R(B_unit))
N = S(B_nn,   R(B_nn))
H = S(B_log,  R(B_log))
最終預測 = median(N, H, U)  # 每筆各算一次
```

### 中位數的手算

| 分支一 | 分支二 | 分支三 |
| --- | --- | --- |
| 980 萬元 | 1,020 萬元 | 1,800 萬元 |

將三個數字由小到大排列，中間值為 1,020 萬元，因此這筆最後預測 1,020 萬元。平均值約為 1,266.67 萬元，會被最高分支拉高。此例只示範中位數對單一極端輸出的反應，沒有真價，不能聲稱中位數在這筆一定更準。

中位數降低一條分支極端偏移的影響；若兩條都偏高，結果仍可能偏高，也可能擋掉某條分支正確的改善。完成這些步驟後，才以 np.rint 取最接近整數（恰好一半時取偶數），並設定至少 1 元；不再乘面積，也不重複套成交參考修正。

## 術語白話表與自我檢查

| 術語 | 在本專題的意思 |
| --- | --- |
| 回歸 | 輸出連續價格數值；不是預測類別 |
| 特徵與標籤 | 特徵是房屋描述；標籤是訓練時已知總價 |
| fit 與 query | fit 用來學習；query 用來預測或事後評估 |

| MAE 與 loss | MAE 是平均絕對差；loss 是訓練調整用的誤差目標 |
| 樣本權重 | 决定哪筆訓練誤差占較高比重；不是改掉標籤 |
| encoder | 把數字或類別轉成模型需要的表示，其學得狀態須保存 |
| prior 先驗 | 由 fit 成交算出的參考價格，先驗 NN 再學調整倍率 |

| 分支與集成 | 先組合部分模型成分支，再組合分支形成最終估價 |
| 過擬合 | 對練習資料表現很好，遇新資料卻失準 |
| 資料洩漏 | 評估時不該知道的答案或資訊提前進入學習 |
| artifact 與 SHA256 | artifact 是保存模型或狀態檔；SHA256 用來辨認檔案是否相同 |

### 試著用自己的話回答

第一，為何 75 萬元 MAE 不是 75％？因為它平均的是金額差，單位仍是元。第二，為何不能用全部資料先算區域均價再回測？因為可能把評估期間的答案放進學習。

第三，為何三分支中位數不是保證？因為兩條分支可能一起偏離。第四，為何推論重現成功仍不是完整重訓？因為模型與 fit 狀態已經保存，沒有在新環境重新完成所有學習步驟。
