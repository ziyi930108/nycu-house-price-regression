## 歷史製作工具

本層的build_presentation.mjs、finalize_presentation.mjs及content.json保留2026-10-13的20頁來源原bytes。它們重建的是當時的20頁稿，不能用來聲稱已重建目前17頁定稿；目前PPT包含其後經確認的文字、刪頁與頁尾精簡。舊工具仍需原適用runtime與技能工具，不屬模型訓練／推論入口。
