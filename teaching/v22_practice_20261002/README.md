# v22上台前練習

完整解壓後開[index.html](index.html)。這是現有簡報的練習工具，沒有增加正式主講頁數，也不需要交易資料、模型或網路。

## 數值自測

[同一筆交易自測](同一筆交易自測.html)沿著一筆假設交易練四步：參考單價乘面積與倍率、組三條初估、對給定修正後價格取中位數、確認不能再乘面積或用未知真價算MAE。全部是教學數字，成交／空間修正結果由題目給定，未執行v22模型。

先自己填，再檢查或看解說；直接看解答不代表自己已會算。工具不儲存或傳送答案，自測不計入正式主講時長。

## 分頁練習與完整計時

[排練計時](排練計時.html)保留目前4,065字、20頁主講正文。

- 分頁練習可反覆練任一頁，累計15分鐘也不當成完整報告時間。
- 完整主講從第1頁開始。20頁都有計時且由你確認講完、按結束、沒有中途暫停，工具才比較12分鐘下限與約15分鐘目標。這仍是手動計時與自評，不是內容已經正確的證明。
- 「練習累計」排除暫停，「開始後經過」包含暫停。切換到投影片仍計時，離席請按暫停。回看前頁會留下次數與操作紀錄。
- 結束後計時固定，仍可回看、補筆記與自評；要再講一次請另開練習，時間不合併。
- 關閉或重整後不自動接成完整主講；舊紀錄留在清單，標明尚未結束。帶入舊筆記會另開分頁練習，時間和勾選從零開始。
- 每個新分頁、每次新練習使用自己的紀錄，避免互相覆寫。沒有清空歷史功能，也不修改舊版工具儲存的資料。

本機瀏覽器儲存可能被清除，或在隱私設定下無法使用。重要紀錄請按下載JSON；不能保存時會顯示提醒，當前記錄仍可下載。換瀏覽器／移動檔案可能看不到舊清單。工具沒有上傳或錄音功能。

使用者尚未實際交回這版的排練紀錄，不能把自動化測試的時間當真人計時。正確時間仍需自然講完，附錄及問答不計入主講。

`sources/`附模板、固定稿本及[標準函式庫建置器](sources/build_rehearsal.py)。需要Python3.10以上；從本資料夾執行以下命令，可在新目錄建立相同排練頁：

```powershell
$toolPython = Read-Host 'Python執行檔完整路徑'
& $toolPython sources/build_rehearsal.py --narrative sources/narrative.json --template sources/rehearsal_template.html --output ../v22-practice-rebuilt/排練計時.html
```

輸出檔必須不存在，來源與字數／配速會核對。這只產生排練頁；自測頁是同包保存的HTML來源，簡報、影片及模型不在此建置範圍。當前檔案身分見同層manifest.json。
