[完整JSON](native_text_audit.json)保存各段文字、字級、背景、色彩、對比及原PPTX SHA。[當時核查紀錄](audit_at_creation.md)保留原bytes，末段「只保存本機／尚未發布」描述的是核查完成當時，當前repo已有本目錄。最新發布身分以Git歷史與SOURCE_MANIFEST為準。
