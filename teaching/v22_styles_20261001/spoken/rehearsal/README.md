# v22 離線上台排練

開啟 [排練頁](v22-rehearsal-reviewed.html)，用瀏覽器即可操作，不需要 Python、模型或網路。

1. 按「開始計時」，看每頁的一句提示，用自己的話說。卡住時展開完整稿。
2. 講完重點與理由後自行勾選，再按下一頁；第12–15頁另附流程順序提醒。
3. 離席按暫停。講完20頁後看紀錄，下載JSON，再依卡住的頁面修改講法。

計時只涵蓋20頁主講，沒有附錄與問答。12分鐘是下限，不是倒數目標；原完整稿規劃17:20。計時不會辨識語音，也不能證明你講完內容，自行勾選也不是自動驗證。沒有本人排練結果。

記錄保存在此瀏覽器；移動HTML、更換瀏覽器或清除瀏覽資料可能讀不到先前記錄，重要結果請下載。切換其他視窗仍計時，以便同時看PowerPoint；導航離開此網頁會保存並暫停。重新開啟先暫停。網頁是獨立檔，GitHub下載時請下載原檔到電腦再開啟；GitHub程式碼預覽不執行互動。

## 製作及驗證

20頁的講稿、標題、提示及配速逐項來自既有核准內容，沒有修改v22模型或原三款PPTX。第12–15頁的順序提醒是輔助，不替代完整稿。這次補足的是查稿與排練操作，不能宣稱已證明講解更容易理解。

[build.py](build.py) 與 [template.html](template.html) 是製作來源。builder目前使用原工作區 `outputs/v22_spoken_20261001/content/` 的兩份JSON，拒絕覆寫既有HTML。它不是在任何clone中直接執行的通用命令；獨立HTML不依賴這些製作路徑。[建置收據](build_reviewed_receipt.json) 保存輸入及輸出SHA。

[瀏覽器測試](browser_verification.json) 使用已安裝Edge與隔離環境、模擬時鐘，檢查20頁全文一致、換頁歸時、暫停排除、重新開啟先暫停、返回事件、摘要更新、下載、清空、手機寬度及無網路資源。這些是工具測試，不是本人排練紀錄。[verify.cjs](verify.cjs) 需原機器的Playwright與Edge路徑；沒有新安裝環境測試。

主線檢視桌面1440px與手機390px的第12頁完整展開畫面，未見裁切、重疊或缺字；沒有實機手機／Safari測試。返回快取以pagehide/pageshow事件模擬，不宣稱所有瀏覽器返回快取已實測。

保留的失敗與修正：首次patch無法建立目錄，建立後成功；預設Playwright瀏覽器不存在，改用已安裝Edge；第一次互動測試要求恰好61秒，實際為61.037秒（含點擊耗時），改檢查61至62秒範圍。子智能體找出返回離頁時間及過期摘要問題，已修正，原始HTML和測試碼保留於本機。詳見[審查歷程](review_history.json)。
