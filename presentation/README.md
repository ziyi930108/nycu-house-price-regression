# v22 上台簡報

[PowerPoint](臺灣房價預測_正式報告_v22.pptx)及[逐頁講稿與問答](講稿與問答.md)。15頁，13頁主講加2頁附錄；主講約9分5秒。

以選定的單一提交模型說明回歸與MAE、資料清理、特徵、六模型與三分支、近期加權、中位數假設例子、時間回測、Public、過擬合限制與保存模型推論重現。主講不使用其他內部版本代號。研究對照與不利證據保留於正式報告附錄；Private仍未知。

4張圖表與5個表格為可編輯PowerPoint物件，各頁都有備忘稿。已重新匯入PPTX並逐頁視覺檢查，未在原生PowerPoint實際開啟驗證。
