## 02　評分與 Public／Private

建議 40 秒。

先說明分數的意義。例如真價一千萬元，預測一千一百萬元，絕對誤差就是一百萬元。把所有評分交易的誤差平均，就是 MAE。公開分數約使用 test 的三成，最終看的 Private 則是另外七成。這與課程另外提供的 valid 不同。分數是總價誤差，不是準確率，也不表示每筆都錯同樣的金額。

## 04　特徵設計

建議 35 秒。

共同基礎有八十七個特徵，包括民國日期、中文樓層、地址與面積比例等轉換。單價 CatBoost 再加八個道路地理欄位，共九十五個，其中二十三個類別欄。這個維度只適用這支樹模型，神經網路另有自己的編碼。編號、目標價格、完整備註與解約情形不作輸入。道路位置也不等同精確門牌。外部地圖沒有成交價格，我們沒有去內政部查 test 的答案。

## 05　模型組合

建議 50 秒。

v22 有三條價格分支，分支內還包含多個模型。單價分支學每單位面積價格，再乘回面積。對數分支用另一種尺度表示總價，神經網路提供不同的非線性預測。每條分支先還原成元，再以訓練資料中的同建案、地址、道路等可比成交與時間趨勢修正，必要時補上空間修正。最後逐筆取三個價格的中位數。這可以降低某一條分支極端輸出的影響，但三條一起錯時仍會錯。完整係數放在附錄。

## 06　近期成交加權

建議 50 秒。

v22 相對 v20 的主要改動，是在單價 CatBoost 原有面積權重上，乘上日期權重。日期採三百六十五天半衰期，所以相差一年的有效成交，較早一筆的日期權重約是一半。圖中的一、零點五、零點二五是正規化前的相對值，實際資料還會正規化再乘面積權重。這不是只留下最近一年，而是仍保留可用舊資料。面積權重讓單價損失對齊總價 MAE，日期權重則讓近期成交更有影響力。

## 07　時間驗證設計

建議 45 秒。

我們用三個完整年度做時間回測，每次只用評分起點以前的 train，預測接下來一年。模型、編碼與價格參考都必須依該期 fit 建立，不能把看過評分價格的全量模型拿回來測。這比把年份隨機混在一起，更接近用過去推估未來。不過這些年度已反覆用於研究，晚期訓練也包含較早的評分年度，因此不是三個獨立試驗，也不是新盲測。

## 09　Kaggle Public 成績

建議 45 秒。

這是使用者實際提交後提供的六個 Public 分數，圖上以萬元顯示。v22 的完整 MAE 是一百九十九萬八千五百六十八點五七零六元，在這六版中最低。相對 v20，平均每筆誤差少約七萬一千兩百六十九元，降低三點四四百分比。這是 MAE 降低，不是準確率增加。較新的 v23 和 v24 在這次 Public 沒有超過 v22，但最終七成 test 的 Private 仍未知，不能把公開結果當成 Private 保證。

## 10　v24 的有利與不利證據

建議 45 秒。

不能只挑支持 v22 的結果。v24 在三個年度的整體 MAE 都比 v22 更低，但 Public 排序相反。v24 單價分支採兩個 CatBoost seed 各半，已移除這條分支原有的 LightGBM 比例，其他兩條分支保持。它在最新年度真價至少一億的三百一十九筆資料中，群內 MAE 又比 v22 增加約九十點九七萬元。這是局部群組的差值，不是全體變差。我們因此保留 v24 作互補候選，不能宣稱 v22 每個評估都最好。

## 11　不利結果與過擬合風險

建議 40 秒。

平均分數會掩蓋不同族群的差異。例如最新回測年度，真價五千萬到一億這一群有一千七百二十五筆，v22 的群內平均誤差仍比 v20 多約二十點四七萬元。這不是全體 MAE 增加二十萬，也不能在預測時按未知真價決定用哪個模型。另一個風險是反覆看同一批驗證資料，方法會逐漸適應這些窗口。因此我們保留不利結果，不把 bootstrap 解讀成 Private 勝率。

## 14　完整模型公式

問答時使用，不列入主講時間。

這頁供模型細節問答。C_unit 是 R79 單價 CatBoost，L_unit 是既有單價 LightGBM，C_raw 是直接總價 CatBoost，C_log 是近期加權對數 CatBoost。N_area 是面積連結 NN，N_prior 是近期加權先驗倍率 NN。所有變數先還原成元。R 為 reference trend，S 同時接收原基準與 reference 結果。最外層取逐筆中位數，沒有在 median 後再乘面積或再次做趨勢。

## 15　程式與參數

問答時使用，不列入主講時間。

R79 是實驗編號，v22 是提交檔版本名。這段只保留核心概念，完整來源還有日期權重來源、列序、特徵、保存與重載檢查。主要 CatBoost 使用 GPU、兩千九百九十九棵樹、深度八、學習率零點零六五與 seed 四十二，沒有 query eval_set 或 early stopping。資料特徵在 house_features.py，全量 fit 在 round79_final_unit.py，組合在 round79_final.py，CSV 檢查在 round79_release.py。交付已新增 src/predict_v22.py，使用原 test 加十七項保存 artifact 真正重跑六模型。這是保存模型推論，不是從零重訓。
