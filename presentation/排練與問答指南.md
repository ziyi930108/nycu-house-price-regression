## 問答準備

以下八題不計主講時間，不需要主講時逐題加念。

### 1. 分數能換算成準確率嗎？

不能直接換算。MAE 是每筆總價絕對誤差的平均，單位為元。若要討論相對誤差，必須另定義百分比指標並用有標籤資料計算，不能從一個 MAE 數字推導出準確率。

### 2. 最終加入 valid，會不會讓回測失去公平性？

這三期年度回測只用 train 中當期起點以前的資料，模型和價格狀態也按該期建立。最終方法確定後才把 valid 加入全量 fit。最後的模型用來預測沒有答案的 test，不能再拿同一批參與 fit 的 valid 分數當成獨立泛化評估。

### 3. 為什麼同時使用單價、面積權重與日期權重？

單價把交易規模分離，但比賽仍評總價，因此單價 CatBoost 乘面積權重，讓其絕對誤差對齊總價誤差。日期權重再提高近期成交影響。三百六十五天是保存配方的固定半衰期，這裡沒有宣稱它是所有地區或所有時期的最佳設定。

### 4. log 模型是不是解決了高價離群值？

它只改變學習時的價格尺度，log 空間 MAE 與元的 MAE 不同。還原成元後仍可能有很大誤差。我們將它當作不同表示的一個分支，沒有聲稱已證明它單獨解決所有離群值。

### 5. 先驗 OOF 是否保證沒有資料洩漏？

它按建案分成五折，避免本建案標籤直接出現在自己的訓練先驗。它不是時間 OOF，不能保證每筆先驗只來自當日以前的交易。年度 query 另以時間切分，query 標籤不進入同一期模型和價格參考。

### 6. 成交參考是否到外部網站查了測試答案？

沒有。價格與可比成交來自課程提供的有標籤資料，外部道路快照只提供非價格地理資訊。空間補充仍只用 fit 中建立的價格狀態，沒有查內政部成交系統的 test 答案。

### 7. 為什麼取中位數？它能保證 MAE 最低嗎？

中位數可降低三條分支中單一極端輸出的影響，這是設計理由。它可能保留兩條以上共有的偏差，而且我們不知道 test 真價，因此不能宣稱這個融合已直接最小化未知 test MAE 或必然最好。

### 8. 程式和模型是否已經完整重現？

指定原始 test 加保存的模型、地理與 fit 狀態，已真實重跑六模型，全部預測和 CSV 與原結果一致。這不是從零重訓的驗證。程式庫不包含原交易資料和約一點四五 GB 的必要私有 artifact，其他環境還要安裝依賴及配置產物，不能只下載程式就保證全鏈重訓成功。

## 字數如何重算

只取 narrative.json 中 is_appendix 為 false 的 script，再統計 Unicode 漢字。以下程式不讀來源、標題或講稿重點：

```python
import json, re
from pathlib import Path
data = json.loads(Path("narrative.json").read_text(encoding="utf-8"))
chars = sum(len(re.findall(r"[㐀-䶿一-鿿豈-﫿]", s["script"]))
            for s in data["slides"] if not s["is_appendix"])
print(chars)
for rate in [250, 275, 285, 300]:
    print(rate, chars / rate)
```
