## 使用界線

價格標籤來自課程資料；禁止到內政部實價登錄系統核對答案。交易表、模型權重、價格先驗、逐筆預測及提交CSV不納入GitHub。來源與文件保存不等於乾淨環境全部六模型端到端重現。

以`python scripts/verify_source.py`核對來源；提交CSV身分檢查見重現說明。這次只重排簡報並同步講稿標題，Word報告保持；未訓練、未改價格、未操作Kaggle。舊文件本機及Git歷史保留。
